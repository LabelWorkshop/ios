## TagStudio for iOS and iPadOS
LabelWorkshop is a port of [TagStudio](https://github.com/TagStudioDev/TagStudio) for iOS. With LabelWorkshop you can use the same tagging and field system you'd expect with TagStudio.

!!! warning
    This project is in an early state. Expect instability and errors.

## Start here

- Follow the [installation guide](installation.md) to install LabelWorkshop.
- See [Getting started](getting_started.md) for the next steps after installation.
