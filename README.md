LabelWorkshop is a port of [TagStudio](https://github.com/TagStudioDev/TagStudio) for iOS. With LabelWorkshop you can use the same tagging and field system you'd expect with TagStudio. Documentation is coming soon!

> [!NOTE]
> For updates, suggestions, help, etc you can [join my discord server](https://discord.gg/vQPgX33dzC)!

> [!CAUTION]
> This project is in an extremly early state. There WILL be bugs, unimplemented features, and crashes.
